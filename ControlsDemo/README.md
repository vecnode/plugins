# ControlsDemo

GUI showcase plugin based on iPlug2's [IPlugControls](https://github.com/iPlug2/iPlug2/tree/master/Examples/IPlugControls) example. Demonstrates knobs, sliders, switches, vector controls, icon fonts, and bitmap assets from the IControls library.

```powershell
.\scripts\build.ps1 -Plugin ControlsDemo -Format vst3 -Config Release
```

Output: `ControlsDemo/build/out/ControlsDemo.vst3/`
